# Pokéwalker Amélioré

App iPhone perso : on rencontre des Pokémon en marchant. Expo + TypeScript, testée avec Expo Go.

```powershell
npm install
npx expo start
```
Scanner le QR code avec l'appareil photo de l'iPhone (Expo Go installé, même Wi-Fi que le PC).

Voir `CLAUDE.md` pour l'architecture, les règles et la roadmap.
